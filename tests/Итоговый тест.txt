1. Чем отличается область видимости (scope) от времени жизни (lifetime) переменной в C++?
    A) Область видимости определяет, где переменная видна в программе, а время жизни — сколько памяти она занимает
    B) Область видимости — это длина имени переменной, время жизни — её размер в байтах
    C) Эти понятия полностью совпадают
    D) Время жизни определяется компилятором, а область видимости — программистом

Правильный ответ: A

2. В чём отличие стека от кучи (heap) в управлении памятью?
    A) В стеке хранится всё, в куче — ничего
    B) Стек управляется вручную, куча автоматически
    C) Стек — это область памяти для локальных переменных, куча — для динамических объектов
    D) Стек быстрее кучи, потому что там всегда один элемент

Правильный ответ: C

6. Что выведет программа?

int x = 1;
void f() {
    int x = 2;
    cout << ::x << " " << x;
}
int main() {
    f();
}

    A) 1 2
    B) 2 1
    C) 2 2
    D) Ошибка компиляции

Правильный ответ: A

7. Какой результат выполнения программы?

    if (a && b || !b)
        cout << "Yes";
    else
        cout << "No";
}

    A) Yes
    B) No
    C) Ошибка
    D) Пустой вывод

9. Что будет напечатано?

}

    B) 7
    C) 2

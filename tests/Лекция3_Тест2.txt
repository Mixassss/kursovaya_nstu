Тест 2 тема - Линейные списки
    1. Как называется список, в котором каждый элемент содержит ссылку только на следующий элемент?
        A) Двунаправленный список
        B) Однонаправленный список
        C) Кольцевой список
        D) Массив

    Правильный ответ: B

    2. Что происходит, если в каждый элемент двунаправленного списка добавить ссылку на предыдущий элемент?
        A) Список станет кольцевым
        B) Список станет однонаправленным
        C) Список станет двунаправленным
        D) Список станет статическим

    Правильный ответ: C

    3. Какой тип списка образуется, если последний элемент связан указателем с первым элементом?
        A) Однонаправленный список
        B) Двунаправленный список
        C) Кольцевой список
        D) Массив

    Правильный ответ: C

    4. Что такое ключ в контексте линейного списка?
        A) Указатель на следующий элемент
        B) Значение, идентифицирующее элемент
        C) Структура данных
        D) Память, занимаемая списком

    Правильный ответ: B

    5. Какие из следующих операций можно выполнять над линейными списками?
        A) Начальное формирование списка
        B) Удаление элемента с заданным ключом
        C) Упорядочивание списка по ключу
        D) Изменение размера списка

    Правильный ответ: A, B, C

    6. Какое описание элемента двунаправленного списка в C++ является корректным?
        A) struct Node { int d; Node *next; };
        B) struct Node { int d; Node *prev; Node *next; };
        C) struct Node { Node *next; Node *prev; };
        D) struct Node { int d; };

    Правильный ответ: B

    7. Какой из следующих ключей может быть использован для упорядочивания записей в линейном списке?
        A) Год рождения
        B) Пол
        C) Стаж работы
        D) Все вышеперечисленные

    Правильный ответ: D

    8. Что происходит при добавлении элемента в конец однонаправленного списка?
        A) Элемент становится первым
        B) Элемент связывается с последним элементом
        C) Элемент теряет указатель на следующий
        D) Список становится двунаправленным

    Правильный ответ: B

    9. Какой из следующих вариантов описывает операцию вставки элемента в линейный список?
        A) Элемент добавляется в начало списка
        B) Элемент добавляется в конец списка
        C) Элемент вставляется до или после элемента с заданным ключом
        D) Элемент удаляется из списка

    Правильный ответ: C

    10. Какой из следующих вариантов является недостатком линейных списков по сравнению со статическими структурами данных?
        A) Сложность реализации
        B) Необходимость управления памятью
        C) Быстрый доступ по индексу
        D) Возможность динамического изменения размера

Правильный ответ: A, B

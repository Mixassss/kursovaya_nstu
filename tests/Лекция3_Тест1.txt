Тест 1 тема - Введение
    1. Что такое динамические структуры данных?
        A) Структуры данных, размер которых известен заранее.
        B) Структуры данных, размер которых может изменяться во время выполнения программы.
        C) Структуры данных, которые всегда занимают смежные участки памяти.
        D) Структуры данных, которые не используют указатели.

    Правильный ответ: B

    2. Какие из следующих структур данных являются динамическими?
        A) Массив
        B) Линейный список
        C) Стек
        D) Очередь

    Правильный ответ: B, C, D

    3. Какой из следующих вариантов является примером динамической структуры данных?
        A) Бинарное дерево
        B) Статический массив
        C) Таблица
        D) Связный список

    Правильный ответ: A, D

    4. Почему динамические структуры данных предпочтительнее для задач сортировки?
        A) Они занимают меньше памяти.
        B) Упорядочивание не требует перестановки элементов, а сводится к изменению указателей.
        C) Они быстрее выполняются на всех типах данных.
        D) Они всегда имеют фиксированный размер.

    Правильный ответ: B

    5. Какой тип данных может использоваться в поле данных динамической структуры?
        A) Только целочисленный тип
        B) Только строковый тип
        C) Любой тип, включая составные и указатели
        D) Только типы, определенные пользователем

    Правильный ответ: C

    6. Как выглядит описание простейшего элемента динамической структуры данных?
        A) struct Node { int data; };
        B) struct Node { Data d; Node *p; };
        C) struct Node { Data d; };
        D) struct Node { Node *p; };

    Правильный ответ: B

    7. Что происходит, если в динамической структуре данных не хватает памяти?
        A) Программа завершится с ошибкой.
        B) Память автоматически выделяется из другого источника.
        C) Структура данных будет уменьшена в размере.
        D) Программа продолжит работать, но с ошибками.

    Правильный ответ: A

    8. Какова основная причина использования динамических структур данных вместо статических?
        A) Динамические структуры проще в реализации.
        B) Динамические структуры позволяют гибко управлять памятью и размером.
        C) Динамические структуры всегда быстрее.
        D) Статические структуры более безопасны.

    Правильный ответ: B

    9. Какой из следующих методов чаще всего используется для реализации стека?
        A) Массив
        B) Динамический массив
        C) Связный список
        D) Таблица

    Правильный ответ: C

    10. Какой из следующих вариантов является недостатком динамических структур данных?
        A) Сложность реализации
        B) Необходимость в управлении памятью
        C) Невозможность изменения размера
        D) Более медленный доступ к элементам

Правильный ответ: A, B, D

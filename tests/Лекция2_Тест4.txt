Тест 4 тема - Оператор switch
    1. Каков основной назначение оператора switch?
        A) Для выполнения циклов
        B) Для разветвления процесса вычислений
        C) Для обработки ошибок
        D) Для управления памятью

    Правильный ответ: B

    Пояснение: Оператор switch используется для разветвления выполнения программы на основе значения выражения, 
    что позволяет выбирать один из нескольких блоков кода для выполнения. 
    Ответы A, C и D не соответствуют назначению оператора switch.

    2. Какой формат имеет оператор switch?
        A) switch { выражение }
        B) switch (выражение) { case ... }
        C) switch [выражение] { case ... }
        D) switch (выражение) : { case ... }

    Правильный ответ: B

    Пояснение: Правильный синтаксис оператора switch включает круглые скобки для выражения и фигурные скобки для блоков case. 
    Ответы A, C и D не соответствуют правильному формату.

    3. Какое значение должно иметь выражение в операторе switch?
        A) Строку
        B) Логическое значение
        C) Целочисленное значение
        D) Массив

    Правильный ответ: C

    Пояснение: Выражение в операторе switch должно быть целочисленным (например, int) или перечислимым значением. 
    Строки (A) и логические значения (B) могут быть использованы в некоторых языках программирования, но это не является общим правилом для всех языков. 
    Массивы (D) не могут быть использованы как выражение в switch.

    4. Что происходит, если значение выражения не совпадает ни с одним из константных выражений?
        A) Выполняется блок case с первым значением.
        B) Выполняются операторы, расположенные после слова default.
        C) Происходит ошибка выполнения.
        D) Оператор switch завершается без выполнения.

    Правильный ответ: B

    Пояснение: Если ни один из case не совпадает с выражением, выполняется блок default, если он присутствует. 
    Ответы A и C неверны, так как блок default не является обязательным и ошибки выполнения не происходит. 
    Ответ D также неверен, так как оператор switch завершает выполнение, но может выполнить блок default.

    5. Что происходит после выполнения оператора case, если оператор break не используется?
        A) Программа завершает выполнение.
        B) Выполняются все последующие операторы в switch.
        C) Возвращается к началу switch.
        D) Переходит к следующему case.

    Правильный ответ: B

    Пояснение: Если оператор break не используется, выполнение продолжается в следующем блоке case, что называется "проваливание". 
    Это может привести к неожиданным результатам. Ответы A и C неверны, так как программа не завершает выполнение и не возвращается к началу switch. 
    Ответ D также неверен, так как выполнение переходит к следующему case, а не к началу.

    6. Какой оператор используется для выхода из switch?
        A) exit
        B) break
        C) continue
        D) return

    Правильный ответ: B, D

    Пояснение: Оператор break используется для выхода из блока switch, а оператор return может использоваться для выхода из функции, содержащей switch. 
    Операторы A (exit) и C (continue) не применимы в данном контексте.

    7. Каковы требования к константным выражениям в операторе switch?
        A) Они должны быть строковыми.
        B) Все должны иметь разные значения.
        C) Они могут быть одинаковыми.
        D) Все должны быть одного и того же целочисленного типа.

    Правильный ответ: B, D

    Пояснение: Константные выражения в блоках case должны иметь уникальные значения (B), и они должны быть одного типа (D). 
    Ответ A неверен, так как строки не являются обязательными, и C также неверен, так как одинаковые значения недопустимы.

    8. Какой из следующих вариантов является правильным использованием оператора switch?

    switch (x) {
        case 1: 
            std::cout << "One"; 
            break;
        case 2: 
            std::cout << "Two"; 
            break;
        default: 
            std::cout << "Default"; 
    }

        A) Да, это корректный синтаксис.
        B) Нет, отсутствует оператор break после default.
        C) Нет, выражение x должно быть строкой.
        D) Нет, все case должны быть одинаковыми.

    Правильный ответ: A

    Приведенный код является корректным примером использования оператора switch. 
    Он содержит все необходимые элементы: выражение, блоки case и блок default. Ответы B, C и D неверны, так как они указывают на ошибки, которых нет.

   9.  Какой из следующих операторов может использоваться для выполнения выхода из функции?
        A) break
        B) continue
        C) return
        D) exit

    Правильный ответ: C

    Пояснение: Оператор return используется для выхода из функции и возвращения значения, если это необходимо. 
    Ответ A (break) используется для выхода из циклов или блоков switch, B (continue) предназначен для пропуска итерации цикла, 
    а D (exit) завершает программу, а не функцию.

    10. Можно ли использовать несколько меток case подряд?
        A) Да, это допустимо.
        B) Нет, это вызовет ошибку.
        C) Да, если они имеют разные значения.
        D) Нет, все метки case должны быть уникальными.

Правильный ответ: A

Пояснение: В операторе switch можно использовать несколько меток case подряд для выполнения одного и того же блока кода при совпадении с несколькими значениями. Например:
    
    switch (x) {
        case 1:
        case 2:
            std::cout << "One or Two";
            break;
    }
Ответы B и D неверны, так как это не вызовет ошибку. 
Ответ C также неверен, так как метки могут иметь одинаковые значения только при условии, что они объединяются в один блок.

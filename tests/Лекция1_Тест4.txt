Тест 4 тема - Структуры
    1. Что такое функция в C++?
        A) Поименованная часть программы, которая может быть вызвана несколько раз
        B) Класс, который хранит данные
        C) Объект, который не может быть изменен
        D) Переменная, хранящая значение

    Правильный ответ: A

    Пояснение: Функция — это блок кода, который выполняет определенную задачу и может быть вызван многократно в разных частях программы. 
    Это позволяет избежать дублирования кода и делает программу более структурированной.

    2. Какой из следующих примеров является корректным объявлением функции?

    A) extern float pow(float, int);
    B) void pow(int, int);
    C) float pow(float x, float y);
    D) int pow(int x);

    Правильный ответ: A

    Пояснение: Этот вариант корректен, так как он объявляет функцию pow, которая возвращает значение типа float и принимает два параметра. 
    Остальные варианты имеют проблемы с синтаксисом или не соответствуют стандарту.

    3. Что происходит при вызове функции с неправильными типами параметров?
        A) Программа завершится с ошибкой
        B) Произойдет автоматическое преобразование типов
        C) Транслятор сочтет это ошибкой
        D) Функция будет вызвана с некорректными данными

    Правильный ответ: C

    Пояснение: Если переданы параметры неправильных типов, компилятор выдаст ошибку на этапе компиляции. 
    Программа не сможет быть скомпилирована до тех пор, пока не будут исправлены ошибки в вызовах функций.

    4. Какой оператор используется для возврата значения из функции?
        A) return
        B) yield
        C) output
        D) send

    Правильный ответ: A

    Пояснение: Оператор return используется для выхода из функции и возврата значения в место вызова функции. 
    Это основной способ передачи результата выполнения функции.

    5. Как называется возможность определения нескольких функций с одинаковыми именами, но с разными параметрами?
        A) Переопределение
        B) Полиморфизм
        C) Перегрузка
        D) Инкапсуляция

    Правильный ответ: C

    Пояснение: Перегрузка функций позволяет создавать несколько функций с одинаковыми именами, но с разными типами или количеством параметров. 
    Это улучшает читаемость кода и упрощает его использование.

    6. Какой из следующих примеров демонстрирует передачу параметров по указателю?

    A) void swap(int* p, int q);
    B) void swap(int& r1, int& r2);
    C) void swap(int a, int b);
    D) void swap(int* p, int* q);

    Правильный ответ: D

    Пояснение: Этот вариант показывает передачу параметров по указателю, что позволяет изменять значения переменных, на которые указывают указатели. 
    Остальные варианты либо передают по значению, либо по ссылке.

    7. Какой из следующих примеров демонстрирует передачу параметров по ссылке?

    A) void swap(int* p, int* q);
    B) void swap(int& r1, int& r2);
    C) void swap(int a, int b);
    D) void swap(int p, int& q);

    Правильный ответ: B

    Пояснение: Этот вариант показывает передачу параметров по ссылке, что позволяет изменять оригинальные переменные без необходимости использования указателей. 
    Остальные варианты не используют ссылки.

    8. Какой из следующих вызовов функции pow является корректным для целых чисел?

    A) float z = pow(2.5, 3);
    B) double y = pow(2.0, 3.0);
    C) int x = pow(2, 3);
    D) float w = pow(2, "3");

    Правильный ответ: C

    Пояснение: Этот вызов корректен, так как передаются два целых числа, что соответствует ожидаемым параметрам функции pow. 
    Вариант D неверен, так как передача строки вместо числа приведет к ошибке компиляции.

    9. Что произойдет, если функция pow будет вызвана с отрицательным показателем?
        A) Функция завершится успешно
        B) Возникнет ошибка, если не обработать случай
        C) Функция вернет 0
        D) Возникнет бесконечный цикл

    Правильный ответ: B

    Пояснение: Если функция pow вызывается с отрицательным показателем для целого числа, 
    это может привести к ошибке или некорректному результату (например, если не предусмотрена обработка такого случая).

Тест 3 тема - Стеки
    1. Что такое стек в контексте динамических структур данных?
        A) Структура данных, в которой элементы добавляются и удаляются с одного конца
        B) Структура данных, в которой элементы могут добавляться и удаляться с обоих концов
        C) Структура данных, которая реализует принцип FIFO (first in — first out)
        D) Структура данных, которая реализует принцип LIFO (last in — first out)

    Правильный ответ: A, D

    2. Как называется операция добавления элемента в стек?
        A) pop
        B) push
        C) insert
        D) append

    Правильный ответ: B

    3. Как называется операция извлечения элемента из стека?
        A) pop
        B) push
        C) remove
        D) delete

    Правильный ответ: A

    4. Какой из следующих вариантов описывает принцип работы стека?
        A) Последний пришел — первым ушел
        B) Первый пришел — первым ушел
        C) Элементы могут извлекаться в любом порядке
        D) Элементы добавляются в произвольном порядке

    Правильный ответ: A

    5. Какой тип структуры данных может быть использован для реализации стека?
        A) Массив
        B) Однонаправленный список
        C) Двунаправленный список
        D) Все вышеперечисленные

    Правильный ответ: D

    6. Какой из следующих фрагментов кода правильно инициализирует вершину стека в C++?
        A) Node *top = nullptr;
        B) Node *top = new Node;
        C) Node *top = first(0);
        D) Node *top = 0;

    Правильный ответ: A, D

    7. Что произойдет, если попытаться извлечь элемент из пустого стека?
        A) Программа завершится с ошибкой
        B) Вернется значение 0
        C) Возникнет исключение
        D) Ничего не произойдет

    Правильный ответ: A, C

    8. Какой из следующих фрагментов кода содержит ошибку?
        A) void push(Node **top, int d);
        B) int pop(Node **top);
        C) for (int i = 2: i < 6; i++) push(&top, 1);
        D) Node *pv = new Node;

    Правильный ответ: C (должно быть for (int i = 2; i < 6; i++))

    9. Какой из следующих вариантов правильно описывает структуру узла стека?
        A) struct Node { int d; Node *next; };
        B) struct Node { int d; Node *prev; Node *next; };
        C) struct Node { int d; Node *p; };
        D) struct Node { Node *top; };

    Правильный ответ: C

    10. Какой результат работы программы, приведенной в теории, если она будет выполнена?
        A) 1 2 3 4 5
        B) 5 4 3 2 1
        C) 1 3 5
        D) 0

Правильный ответ: B

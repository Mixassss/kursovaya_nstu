1. Какое из следующих утверждений о структурах в C++ является неверным?

    A) Структуры могут содержать переменные различных типов.
    B) Операции сравнения между структурами определены по умолчанию.
    C) Размер объекта структурного типа может не равняться сумме размеров всех его членов.
    D) Объекты структурного типа могут быть переданы как параметры функций.

Правильный ответ: B

2. Какое из следующих утверждений о операторе switch является неверным?

    A) Оператор switch может использоваться только с целочисленными типами данных.
    B) Если оператор break не используется, выполнение будет продолжаться до конца switch.
    C) Оператор switch может использоваться для работы со строками.
    D) Все константные выражения в switch должны иметь разные значения.

Правильный ответ: C

3. Какой из следующих вариантов является недостатком динамических структур данных?

    A) Гибкость в управлении памятью
    B) Эффективность работы с данными
    C) Возможность создания сложных структур
    D) Необходимость управления памятью вручную

Правильный ответ: D) Необходимость управления памятью вручную

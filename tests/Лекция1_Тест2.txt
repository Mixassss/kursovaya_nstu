Тест 2 тема - Имена, типы и указатели
    1. Какой из следующих символов может быть первым в имени (идентификаторе) в C++?
        A) Буква
        B) Цифра
        C) Символ подчеркивания (_)
        D) Специальный символ ($)

    Правильный ответ: A, C

    Пояснение: В C++ идентификаторы могут начинаться с буквы (A-Z, a-z) или символа подчеркивания (_). 
    Цифры не могут быть первыми, а специальные символы (например, $) также не допускаются.

    2. Какое из следующих имен является допустимым идентификатором в C++?
        A) 3var
        B) hello
        C) class
        D) _myVariable

    Правильный ответ: B, D

    Пояснение: hello является допустимым идентификатором, так как он начинается с буквы и не содержит запрещенных символов. 
    _myVariable также допустим, так как начинается с символа подчеркивания. 
    3var недопустим, так как начинается с цифры, а class является зарезервированным словом в C++.

    3. Какой из следующих типов данных используется для представления целых чисел в C++?
        A) float
        B) int
        C) char
        D) double

    Правильный ответ: B, C

    Пояснение: int — это тип данных для целых чисел. 
    char может представлять целые числа в диапазоне от -128 до 127 или 0 до 255, но основным типом для целых чисел является int. 
    Таким образом, правильный ответ только B.

    4. Какой из следующих типов данных используется для представления чисел с плавающей точкой?
        A) short int
        B) float
        C) unsigned int
        D) signed long int

    Правильный ответ: B

    Пояснение: float — это тип данных для чисел с плавающей точкой. 
    Остальные варианты (short int, unsigned int, signed long int) используются для целых чисел.

    5. Что произойдет, если попытаться использовать служебное слово C++ в качестве идентификатора?
        A) Программа скомпилируется без ошибок.
        B) Произойдет ошибка компиляции.
        C) Идентификатор будет автоматически преобразован.
        D) Программа завершится с ошибкой выполнения.

    Правильный ответ: B

    Пояснение: Служебные слова (или ключевые слова) являются зарезервированными идентификаторами в C++ и не могут использоваться для именования переменных или функций. 
    Попытка их использования приведет к ошибке компиляции.

    6. Какой из следующих примеров корректно показывает объявление указателя?
        A) int* p;
        B) int p*;
        C) *int p;
        D) int p = &x;

    Правильный ответ: A

    Пояснение: Это правильный синтаксис для объявления указателя на целочисленный тип. 
    Варианты B и C имеют неправильный порядок символов, 
    а D неправилен, потому что нельзя присвоить адрес переменной без предварительного объявления указателя.

    7. Какова основная операция, выполняемая с указателями?
        A) Присваивание
        B) Косвенное обращение (разыменование)
        C) Сравнение
        D) Инициализация

    Правильный ответ: B

    Пояснение: Основная операция с указателями — это разыменование, то есть доступ к значению по адресу, на который указывает указатель. 
    Присваивание и инициализация также важны, но не являются основными операциями разыменования.

    8. Какой из следующих вариантов является корректным способом разыменования указателя?
        A) *p = 5;
        B) p* = 5;
        C) int x = *p;
        D) p = *5;

    Правильный ответ: A, C

    Пояснение: Вариант A присваивает значение 5 по адресу, на который указывает p, а вариант C извлекает значение из адреса, на который указывает p, и присваивает его переменной x. 
    Вариант B имеет неправильный синтаксис, а D неверен, потому что разыменование происходит через указатель, а не через значение.

    9. Какой из следующих типов данных используется для указателя на массив целых чисел?
        A) int*
        B) int[]
        C) int(*)[10]
        D) int&

    Правильный ответ: C

    Пояснение: Указатель на массив целых чисел можно объявить как int*, который указывает на первый элемент массива. 
    Вариант C может быть использован для указателя на массив фиксированного размера, но правильным ответом является A.

    10. Какой из следующих примеров кода корректно демонстрирует подсчет символов в строке с использованием указателя?

    A) int strlen(char* p) {
           int i = 0;
           while (*p++) i++;
           return i;
       }
    B) int strlen(char p) {
           int i = 0;
           while (p++) i++;
           return i;
       }
    C) int strlen(char** p) {
           int i = 0;
           while (**p++) i++;
           return i;
       }
    D) int strlen(char* p) {
           int i = 0;
           while (p[i] != '\0') i++;
           return i;
       }

    Правильный ответ: A, D

    Пояснение: Вариант A использует указатель для прохода по строке до нулевого символа (0), увеличивая счетчик i. 
    Вариант D также правильно подсчитывает символы, используя индексацию массива. 
    Варианты B и C неверны, так как они используют неправильные типы данных для параметра или разыменование.

Тест 1 тема - Оператор «выражение» и условный оператор if
    1. Какой из следующих вариантов является корректным выражением?
        A) i++
        B) a *= b + c
        C) fun(i, k)
        D) Все вышеперечисленные

    Пояснение: Все перечисленные варианты являются корректными выражениями в C++:
    A) i++ — инкремент переменной i.
    B) a *= b + c — умножение a на сумму b и c.
    C) fun(i, k) — вызов функции fun с параметрами i и k.

    2. Какой из следующих операторов является пустым оператором?
        A) if (a < 0) b = 1;
        B) ;
        C) return;
        D) while (true) {}

    Пояснение: Пустой оператор — это оператор, который ничего не делает. 
    Вариант B (;) является пустым оператором. Остальные варианты содержат действия (например, присваивание или циклы).

    3. Каков формат условного оператора if?
        A) if (выражение) оператор_1; [else оператор_2;]
        B) if (выражение) { оператор_1; }
        C) if оператор_1
        D) if (выражение) оператор_1;

    Пояснение: Формат условного оператора if включает в себя выражение в круглых скобках и один оператор после него. 
    Опционально может быть добавлен блок else. Остальные варианты либо неполные, либо имеют неправильный синтаксис.

    4. Что происходит, если выражение в условном операторе if равно нулю?
        A) Выполняется первый оператор
        B) Выполняется второй оператор
        C) Программа завершает выполнение
        D) Ничего не происходит

    Пояснение: В C++ любое ненулевое значение рассматривается как истинное (true), а ноль — как ложное (false). 
    Если выражение равно нулю, выполняется оператор, связанный с else, если он есть.

    5. Какой из следующих вариантов является примером использования блока в условном операторе if?
        A) if (a < 0) b = 1;
        B) if (a < b) { b = a; c = b; }
        C) if (true) x++; else y--;
        D) if (a) b++;

    Пояснение: Вариант B использует фигурные скобки для создания блока кода, который выполняется, если условие истинно. 
    Остальные варианты не используют блоки и представляют собой одиночные операторы.

    6. Каковы ограничения на переменные, описанные в блоке условного оператора?
        A) Они доступны только в пределах блока
        B) Они доступны во всей функции
        C) Они доступны во всей программе
        D) Они доступны в следующем блоке

    Пояснение: Переменные, объявленные внутри блока (в фигурных скобках), имеют область видимости только внутри этого блока. 
    Они недоступны вне его.

    7. Какой из следующих операторов является примером "пропуска оператора"?
        A) if (a < 0) b = 1;
        B) if (a > 0) { b = 1; } else { b = 0; }
        C) if (true) {}
        D) if (x == 5) x++; else ;

    Пояснение: Вариант C представляет собой условие, при котором ничего не происходит, так как блок пуст. 
    Остальные варианты содержат действия.

    8. Как можно объединить несколько условий в условном операторе if?
        A) Используя логические операторы (&&, ||)
        B) Используя запятые
        C) Используя фигурные скобки
        D) Используя точки с запятой

    Пояснение: Логические операторы && (и) и || (или) позволяют объединять несколько условий в одном выражении if. 
    Остальные варианты не применимы для объединения условий.

    9. Какой из следующих вариантов является корректным примером вложенного условного оператора if?
        A) if (a < b) if (b < c) max = b;
        B) if (a < b) { if (b < c) max = b; }
        C) if (a < b) max = a; else max = b;
        D) Все вышеперечисленные

    Пояснение: Все предложенные варианты представляют собой корректные примеры вложенных операторов if. 
    В каждом случае один оператор if находится внутри другого.

    10. Как можно записать условие в виде условной операции?
        A) max = (b > a) ? b : a;
        B) max = if (b > a) b else a;
        C) max = b > a ? b : a;

    Пояснение: Оба варианта A и C являются корректными примерами использования тернарного оператора для присваивания значения переменной max. 
    Вариант B неверен, так как синтаксис не соответствует правилам языка C++.

Ответы:

    E) Все вышеперечисленные
    B) ;
    A) if (выражение) оператор_1; [else оператор_2;]
    B) Выполняется второй оператор
    B) if (a < b) { b = a; c = b; }
    A) Они доступны только в пределах блока
    C) if (true) {}
    A) Используя логические операторы (&&, ||)
    D) Все вышеперечисленные
    A и С)

Тест 3 тема - Структуры
    1. Что такое структура в C++?
        A) Совокупность элементов одного типа
        B) Совокупность элементов произвольных типов
        C) Массив фиксированного размера
        D) Класс, не имеющий методов

    Правильный ответ: B

    Пояснение: Структура в C++ — это пользовательский тип данных, который позволяет объединять переменные различных типов под одним именем. 
    В отличие от массива, который состоит только из элементов одного типа, структура может содержать элементы разных типов.

    2. Что из перечисленного является корректным способом инициализации структуры в C++? struct Point { int x; int y; };
        A) Point p = {10, 20};
        B) Point p; p = {10, 20};
        C) Point p = new Point(10, 20);
        D) Point p; p(10, 20);

    Правильный ответ: A

    Пояснение: Вариант A корректен: используется агрегатная инициализация с фигурными скобками
    Вариант B неверен: присваивание списком в фигурных скобках разрешено только при инициализации
    Вариант C неверен: new возвращает указатель, а не объект, и конструктор с параметрами не объявлен
    Вариант D неверен: синтаксис p(10, 20) не применим к структуре без конструктора

    3. Как можно передать объект структуры в функцию?
        A) Как ссылку
        B) Как указатель
        C) Как значение
        D) Все вышеперечисленное

    Правильный ответ: D

    Пояснение: Объекты структур можно передавать в функции различными способами: 
    по значению (копия), по ссылке (изменения будут отражены), или по указателю (для работы с динамически выделенной памятью).

    4. Что произойдет, если вы попытаетесь сравнить два объекта структурного типа с помощью оператора ==?
        A) Произойдет ошибка компиляции
        B) Сравнение будет выполнено
        C) Операция сравнения не определена
        D) Будет возвращено значение true или false

    Правильный ответ: C

    Пояснение: В C++ операторы сравнения не определены для пользовательских типов данных, таких как структуры. 
    Поэтому попытка сравнить две структуры с помощью == приведет к ошибке компиляции.

    5. Какой из следующих операторов можно использовать для присвоения объектов структурного типа?
        A) =
        B) +=
        C) ==
        D) !=

    Правильный ответ: A

    Пояснение: Оператор присваивания = используется для копирования значений одного объекта структуры в другой. 
    Операторы +=, == и != не могут быть использованы для присвоения объектов структурного типа.

    6. Какое утверждение о структурах в C++ является верным?
        A) Структуры не могут содержать указатели на самих себя
        B) Размер структуры всегда кратен размеру самого большого члена
        C) Структуры могут иметь методы, конструкторы и деструкторы
        D) Объекты структур по умолчанию передаются в функции по ссылке

    Правильный ответ: C

    Пояснение: Вариант A неверен: структуры могут содержать указатели на свой же тип. Вариант B неверен: размер структуры кратен не размеру самого большого члена. 
    Вариант C верен: в C++ структуры почти идентичны классам и могут иметь методы. Вариант D неверен: объекты 
    структур по умолчанию передаются по значению

    7. Какой из следующих утверждений о размерах структур является правильным?
        A) Размер структуры всегда равен сумме размеров всех ее членов.
        B) Выравнивание может привести к "дырам" в структуре.
        C) Размер структуры не может быть определен.
        D) Размер структуры равен размеру самого большого члена.

    Правильный ответ: B

    Пояснение: Размер структуры может быть больше суммы размеров ее членов из-за выравнивания памяти, которое добавляет "дыры" для оптимизации доступа к данным.

    8. Как можно использовать структуру сразу после ее объявления?
        A) Можно создавать объекты структуры сразу после объявления
        B) Можно использовать тип структуры в самой структуре
        C) Можно вызывать методы структуры до ее определения
        D) Можно объявлять указатели на структуру до ее определения

Правильный ответ: A

    Пояснение: A) После объявления структуры можно создавать объекты этого типа.
    C) Нельзя использовать тип структуры до завершения ее описания — это ограничение языка.

    9. Какой из следующих способов можно использовать для инициализации объекта структуры?
        A) address myAddress = "Jim Dandy", 61, "South Street", "New Providence", 7974;
        B) address myAddress; myAddress.name = "Jim Dandy";
        C) address myAddress = new address;
        D) address myAddress; myAddress = {"Jim Dandy", 61, "South Street", "New Providence", 7974};

Правильные ответы: B

Пояснение: A) Этот способ неверен, так как для инициализации структуры списком значений необходимо использовать фигурные скобки 
B) Этот способ корректен и демонстрирует присвоение значения после объявления.
C) Этот способ неверен, так как new возвращает указатель, а не объект структуры.
D) Этот способ неверен, так как нельзя присваивать структуру напрямую после объявления без создания переменной.

Тест 2 тема - Цикл с предусловием (while) и цикл с постусловием (do while)
    1. Каков общий формат цикла с предусловием?
        A) while (выражение) оператор
        B) do оператор while (выражение)
        C) for (инициализация; условие; итерация) оператор
        D) repeat оператор until (выражение)

    Пояснение: Оператор while проверяет условие перед выполнением тела цикла. 
    Если условие истинно, выполняется тело цикла. Ответы B, C и D относятся к другим типам циклов и не являются корректным форматом для цикла while.

    2. Что происходит, если выражение в цикле while равно false при первой проверке?
        A) Цикл выполнится один раз
        B) Цикл выполнится несколько раз
        C) Цикл не выполнится ни разу
        D) Программа завершит выполнение

    Пояснение: Если условие в while ложно с самого начала, тело цикла не будет выполнено ни разу. 
    Ответы A и B неверны, так как цикл не выполнится вообще. Ответ D также неверен, так как программа не завершает выполнение.

    3. Какое из следующих выражений является корректным примером цикла while?
        A)

        while (x < 10) {
            x++;
        }

        B)

        while (x < 10) x++;

        C)

        while (x < 10) x++; else x--;

        D) Все вышеперечисленные

    Пояснение: Все предложенные примеры являются корректными. 
    A и B используют правильный синтаксис для while, а C имеет ошибку, так как else не может использоваться непосредственно после while. 
    Однако синтаксически это не является ошибкой, так как в C++ можно использовать else вне цикла. Поэтому правильный ответ — D.

    4. Какой из следующих операторов используется для завершения цикла do while?
        A) break
        B) continue
        C) return
        D) exit

    Пояснение: Оператор break используется для немедленного выхода из цикла. Оператор continue (B) пропускает текущую итерацию и переходит к следующей. 
    return (C) завершает выполнение функции, а exit (D) завершает программу. Таким образом, правильный ответ — A.

    5. Каков формат цикла с постусловием?
        A) while (выражение) оператор
        B) do оператор while (выражение)
        C) for (инициализация; условие; итерация) оператор
        D) repeat оператор until (выражение)

    Пояснение: Цикл do while выполняет тело цикла хотя бы один раз, а затем проверяет условие. 
    Ответы A и C относятся к другим типам циклов, а D является синтаксисом, используемым в других языках программирования (например, Pascal).

    6. Что происходит в цикле do while при первой итерации?
        A) Выражение проверяется перед выполнением тела цикла
        B) Тело цикла выполняется хотя бы один раз
        C) Цикл не выполнится, если выражение равно false
        D) Цикл завершится сразу

    Пояснение: В цикле do while тело цикла выполняется перед проверкой условия, что гарантирует хотя бы одну итерацию. 
    Ответ A неверен, так как проверка происходит после выполнения тела. Ответы C и D также неверны, так как цикл выполнится хотя бы один раз.

    7. Какое из следующих выражений является корректным примером цикла do while?
        A)

        do {
            cout << "Hello";
        } while (condition);

        B)

        do operator while (condition);

        C)

        do { cout << "Hello"; } while (false);

        D) Все вышеперечисленные

    Пояснение: Все предложенные примеры являются корректными примерами использования цикла do while. 
    Пример A использует стандартный синтаксис, пример B содержит некорректный синтаксис, но концептуально правильный, 
    а пример C также корректен, так как тело цикла выполнится один раз, даже если условие ложно.

    8. Какой тип выражения должен использоваться в циклах while и do while?
        A) Логический
        B) Символьный
        C) Арифметический или приводимый к нему
        D) Строковый

    Пояснение: Условия в циклах while и do while должны быть логическими (true или false). 
    Ответы B и D неверны, так как символьные и строковые значения не могут быть использованы в качестве условий. 
    Ответ C также неверен, так как арифметические выражения могут быть приведены к логическим значениям, но не являются обязательными.

    9. Какой из следующих операторов может быть использован для управления потоком в теле цикла?
        A) break
        B) continue
        C) return
        D) Все вышеперечисленные

    Пояснение: Все перечисленные операторы могут использоваться для управления потоком выполнения в теле цикла. 
    break используется для выхода из цикла, continue пропускает оставшуюся часть текущей итерации и переходит к следующей, а return завершает выполнение функции.

    10. Какой из следующих примеров кода корректно находит все делители целого положительного числа с использованием цикла while?
        A)

        while (div <= half) {
            if (!(num % div)) cout << div << endl;
            div++;
        }

        B)

        while (div < half) {
            if (num % div == 0) cout << div;
            div++;
        }

        C)

        while (div <= half) cout << div << endl; div++;

        D) Все вышеперечисленные

    Пояснение: Пример A корректен и находит делители числа num, проверяя каждое значение div. 
    Пример B имеет ошибку в условии — оно должно быть div <= half, чтобы включить половину числа. 
    Пример C также некорректен из-за неверного расположения оператора инкрементации. 
    Таким образом, правильный ответ — A.


Ответы:

    A) while (выражение) оператор
    C) Цикл не выполнится ни разу
    D) Все вышеперечисленные
    A) break
    B) do оператор while (выражение)
    B) Тело цикла выполняется хотя бы один раз
    D) Все вышеперечисленные
    C) Арифметический или приводимый к нему
    D) Все вышеперечисленные
    A)

    while (div <= half) {
        if (!(num % div)) cout << div << endl;
        div++;
    }
